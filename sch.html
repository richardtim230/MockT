📋 What is ExamGuard?

ExamGuard is a complete school management system that helps your school run smoothly. It handles student records, grades, attendance, exam results, and communication between the school and parents. ExamGuard provides six main sections for different users:

📊 Admin Dashboard

Manage everything - students, teachers, finance, and reports. See all school information in one easy place.
